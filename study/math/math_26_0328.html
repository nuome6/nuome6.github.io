一、知识点概述

今天学两块内容：

  1. 集合运算：昨天学了交/并/补的定义，今天重点练运算性质和综合应用
  2. 逻辑联结词：充分条件、必要条件、充要条件，以及"且""或""非"

核心思想：集合是描述数学对象的工具，逻辑是判断命题真假的工具。考研数学里，集合往往和逻辑一起考。

二、核心公式

2.1 集合运算性质

设全集为 UUU，A,B⊆UA, B \subseteq UA,B⊆U：

交换律：

A∩B=B∩AA \cap B = B \cap A A∩B=B∩A

A∪B=B∪AA \cup B = B \cup A A∪B=B∪A

结合律：

(A∩B)∩C=A∩(B∩C)(A \cap B) \cap C = A \cap (B \cap C) (A∩B)∩C=A∩(B∩C)

(A∪B)∪C=A∪(B∪C)(A \cup B) \cup C = A \cup (B \cup C) (A∪B)∪C=A∪(B∪C)

分配律：

A∩(B∪C)=(A∩B)∪(A∩C)A \cap (B \cup C) = (A \cap B) \cup (A \cap C) A∩(B∪C)=(A∩B)∪(A∩C)

A∪(B∩C)=(A∪B)∩(A∪C)A \cup (B \cap C) = (A \cup B) \cap (A \cup C) A∪(B∩C)=(A∪B)∩(A∪C)

德摩根律（重点！）：

∁U(A∩B)=(∁UA)∪(∁UB)\complement_U (A \cap B) = (\complement_U A) \cup (\complement_U B) ∁U​(A∩B)=(∁U​A)∪(∁U​B)

∁U(A∪B)=(∁UA)∩(∁UB)\complement_U (A \cup B) = (\complement_U A) \cap (\complement_U B) ∁U​(A∪B)=(∁U​A)∩(∁U​B)

记法口诀：补号穿进去，∩ ↔ ∪ 互换

吸收律：

A∩(A∪B)=AA \cap (A \cup B) = A A∩(A∪B)=A

A∪(A∩B)=AA \cup (A \cap B) = A A∪(A∩B)=A

2.2 逻辑联结词

联结词符号含义真假规则
且p∧qp \land qp∧qp 和 q 都成立同真为真，一假即假
或p∨qp \lor qp∨qp 和 q 至少一个成立同假为假，一真即真
非¬p\neg p¬pp 的否定真变假，假变真

2.3 充分条件与必要条件

定义：

  • 若 p⇒qp \Rightarrow qp⇒q，则称 p 是 q 的充分条件（p 成立就足够推出 q）
  • 若 p⇒qp \Rightarrow qp⇒q，则称 q 是 p 的必要条件（要 q 成立，必须 p 先成立）
  • 若 p⇔qp \Leftrightarrow qp⇔q，则称 p 是 q 的充要条件（等价）

记忆技巧：

"⇒\Rightarrow⇒" 箭头前面是充分，后面是必要

简记："前推后充分，后推前必要"

四种命题关系：

命题形式与原命题关系
原命题p⇒qp \Rightarrow qp⇒q—
逆命题q⇒pq \Rightarrow pq⇒p不一定同真同假
否命题¬p⇒¬q\neg p \Rightarrow \neg q¬p⇒¬q不一定同真同假
逆否命题¬q⇒¬p\neg q \Rightarrow \neg p¬q⇒¬p与原命题等价！

重要结论：原命题 ⇔\Leftrightarrow⇔ 逆否命题

证明不了原命题时，可以转而去证逆否命题。

2.4 全称量词与存在量词

  • 全称量词：∀x∈A,p(x)\forall x \in A, p(x)∀x∈A,p(x)（对所有 x，p(x) 成立）
  • 存在量词：∃x∈A,p(x)\exists x \in A, p(x)∃x∈A,p(x)（存在 x，使 p(x) 成立）

否定的写法：

¬(∀x,p(x))=∃x,¬p(x)\neg(\forall x, p(x)) = \exists x, \neg p(x) ¬(∀x,p(x))=∃x,¬p(x)

¬(∃x,p(x))=∀x,¬p(x)\neg(\exists x, p(x)) = \forall x, \neg p(x) ¬(∃x,p(x))=∀x,¬p(x)

简记：否全称变存在，否存在变全称

三、例题讲解

例题 1（基础 — 集合运算）

题目： 设 U={1,2,3,4,5,6}U = \{1,2,3,4,5,6\}U={1,2,3,4,5,6}，A={1,2,3,4}A = \{1,2,3,4\}A={1,2,3,4}，B={3,4,5,6}B = \{3,4,5,6\}B={3,4,5,6}，求：

(1) A∩BA \cap BA∩B　　(2) A∪BA \cup BA∪B　　(3) ∁UA\complement_U A∁U​A　　(4) ∁U(A∩B)\complement_U(A \cap B)∁U​(A∩B)

解：

(1) A ∩ B = {3,4}（两个集合都有的元素）

(2) A ∪ B = {1,2,3,4,5,6}（两个集合所有元素合起来）

(3) ∁UA\complement_U A∁U​A = {5,6}（全集 U 中不在 A 里的元素）

(4) 先算 A∩B={3,4}A \cap B = \{3,4\}A∩B={3,4}，再取补集：

∁U(A∩B)={1,2,5,6}\complement_U(A \cap B) = \{1,2,5,6\} ∁U​(A∩B)={1,2,5,6}

验证德摩根律：∁U(A∩B)=(∁UA)∪(∁UB)\complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B)∁U​(A∩B)=(∁U​A)∪(∁U​B)

  • 左边 =
  • 右边 = {5,6} ∪ {1,2} = {1,2,5,6} ✅

例题 2（基础 — 充分必要条件）

题目： 判断"x>2x > 2x>2"是"x2>4x^2 > 4x2>4"的什么条件？

解：

先检验 p⇒qp \Rightarrow qp⇒q：若 x>2x > 2x>2，则 x2>4x^2 > 4x2>4 吗？

取 x=3x = 3x=3：32=9>43^2 = 9 > 432=9>4 ✅

事实上 x>2>0x > 2 > 0x>2>0 时，x2>22=4x^2 > 2^2 = 4x2>22=4，所以 p⇒qp \Rightarrow qp⇒q 成立。

再检验 q⇒pq \Rightarrow pq⇒p：若 x2>4x^2 > 4x2>4，则 x>2x > 2x>2 吗？

取 x=−3x = -3x=−3：(−3)2=9>4(-3)^2 = 9 > 4(−3)2=9>4，但 −3<2-3 < 2−3<2 ❌

所以 q⇒pq \Rightarrow pq⇒p 不成立。

结论： "x>2x > 2x>2"是"x2>4"x^2 > 4"x2>4"的充分不必要条件。

例题 3（综合 — 集合与逻辑结合，贴近考研）

题目： 已知集合 A={x∣x2−3x+2=0}A = \{x \mid x^2 - 3x + 2 = 0\}A={x∣x2−3x+2=0}，B={x∣ax−2=0}B = \{x \mid ax - 2 = 0\}B={x∣ax−2=0}，若 B⊆AB \subseteq AB⊆A，求实数 aaa 的所有取值。

解：

第一步：求集合 A

解方程 x2−3x+2=0x^2 - 3x + 2 = 0x2−3x+2=0：

x2−3x+2=(x−1)(x−2)=0x^2 - 3x + 2 = (x-1)(x-2) = 0 x2−3x+2=(x−1)(x−2)=0

所以 A={1,2}A = \{1, 2\}A={1,2}

第二步：分析集合 B

B={x∣ax−2=0}B = \{x \mid ax - 2 = 0\}B={x∣ax−2=0}，即 ax=2ax = 2ax=2

需要分情况讨论：

情况①：a=0a = 0a=0

方程变为 0⋅x=20 \cdot x = 20⋅x=2，即 0=20 = 20=2，无解。

所以 B=∅B = \emptysetB=∅。

空集是任何集合的子集，B⊆AB \subseteq AB⊆A 成立 ✅

情况②：a≠0a \neq 0a=0

解为 x=2ax = \dfrac{2}{a}x=a2​，即 B={2a}B = \left\{\dfrac{2}{a}\right\}B={a2​}

要使 B⊆AB \subseteq AB⊆A，需要 2a∈A={1,2}\dfrac{2}{a} \in A = \{1, 2\}a2​∈A={1,2}

  • 若 2a=1\dfrac{2}{a} = 1a2​=1，则 a=2a = 2a=2
  • 若 2a=2\dfrac{2}{a} = 2a2​=2，则 a=1a = 1a=1

第三步：汇总

a∈{0,1,2}a \in \{0, 1, 2\} a∈{0,1,2}

易错点： 忘记 a=0a = 0a=0 的情况！a=0a = 0a=0 时 B 是空集，空集 ⊆ 任何集合。

例题 4（考研风格 — 命题真假判断）

题目： 判断下列命题的真假：

(1) ∃x∈R,  x2+1<0\exists x \in \mathbb{R}, \; x^2 + 1 < 0∃x∈R,x2+1<0

(2) ∀x∈R,  x2+2x+1≥0\forall x \in \mathbb{R}, \; x^2 + 2x + 1 \geq 0∀x∈R,x2+2x+1≥0

解：

(1) 对任意实数 xxx，x2≥0x^2 \geq 0x2≥0，所以 x2+1≥1>0x^2 + 1 \geq 1 > 0x2+1≥1>0。

不存在使 x2+1<0x^2 + 1 < 0x2+1<0 的实数。命题为假 ❌

(2) x2+2x+1=(x+1)2≥0x^2 + 2x + 1 = (x+1)^2 \geq 0x2+2x+1=(x+1)2≥0 对所有实数 xxx 恒成立。命题为真 ✅

写该命题的否定：∃x∈R,  (x+1)2<0\exists x \in \mathbb{R}, \; (x+1)^2 < 0∃x∈R,(x+1)2<0（为假，与原命题真假相反）

四、避坑指南

⚠️ 1. 空集！空集！空集！

集合题最大的坑就是忘记空集。

  • B⊆AB \subseteq AB⊆A 时，别忘了 B=∅B = \emptysetB=∅
  • A∩B=∅A \cap B = \emptysetA∩B=∅ 的情况也要单独讨论
  • 养成习惯：做集合题第一步，问自己"空集要考虑吗？"

⚠️ 2. 充分/必要搞反

"ppp 是 qqq 的充分条件" = p⇒qp \Rightarrow qp⇒q

容易搞反方向。记住：充分是"有它就够了"，必要是"没它就不行"

比如"下雨"是"地湿"的充分不必要条件（下雨肯定地湿，但地湿不一定是下雨，可能是洒水车）。

⚠️ 3. 否定量词只否量词不否条件

¬(∀x,x>0)\neg(\forall x, x > 0)¬(∀x,x>0) 的正确写法是 ∃x,x≤0\exists x, x \leq 0∃x,x≤0

常见错误：写成 ∃x,x>0\exists x, x > 0∃x,x>0（只变了量词，忘了取反条件）

⚠️ 4. 逆否命题 ≠ 逆命题

原命题和逆否命题等价，和逆命题、否命题不等价！

这是考研选择题常考的陷阱。
