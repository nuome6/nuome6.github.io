二次函数应用 — 判别式与韦达定理

一、知识点概述

二次函数 f(x)=ax2+bx+c (a≠0)f(x) = ax^2 + bx + c\ (a \neq 0)f(x)=ax2+bx+c (a=0) 与对应的一元二次方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 密切相关。今天我们重点掌握两个核心工具：

  1. 判别式 Δ\DeltaΔ：判断方程根的情况
  2. 韦达定理（根与系数的关系）：不求根就能得到根的和与积

这两个工具是后续学函数零点、解析几何的基础，必须熟练掌握。

二、核心公式

2.1 判别式

对于一元二次方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0，判别式为：

Δ=b2−4ac\Delta = b^2 - 4ac Δ=b2−4ac

2.2 韦达定理（根与系数的关系）

若 x1,x2x_1, x_2x1​,x2​ 是方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 的两个根，则：

x1+x2=−ba\boxed{x_1 + x_2 = -\frac{b}{a}} x1​+x2​=−ab​​

x1⋅x2=ca\boxed{x_1 \cdot x_2 = \frac{c}{a}} x1​⋅x2​=ac​​

记忆口诀：和 = −ba-\dfrac{b}{a}−ab​，积 = ca\dfrac{c}{a}ac​

三、例题讲解

例题1（简单）：判别式判断根的情况

题目：判断方程 2x2−3x+5=02x^2 - 3x + 5 = 02x2−3x+5=0 的根的情况。

解：

Δ=(−3)2−4×2×5=9−40=−31<0\Delta = (-3)^2 - 4 \times 2 \times 5 = 9 - 40 = -31 < 0 Δ=(−3)2−4×2×5=9−40=−31<0

因为 Δ<0\Delta < 0Δ<0，所以方程无实根。

对应的抛物线 y=2x2−3x+5y = 2x^2 - 3x + 5y=2x2−3x+5 开口向上且在 xxx 轴上方，与 xxx 轴无交点。

例题2（简单）：韦达定理基础应用

题目：已知 x1,x2x_1, x_2x1​,x2​ 是方程 x2−5x+6=0x^2 - 5x + 6 = 0x2−5x+6=0 的两根，不解方程，求 x12+x22x_1^2 + x_2^2x12​+x22​。

解：

由韦达定理：x1+x2=5x_1 + x_2 = 5x1​+x2​=5，x1x2=6x_1 x_2 = 6x1​x2​=6

x12+x22=(x1+x2)2−2x1x2=25−12=13x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2 = 25 - 12 = \boxed{13} x12​+x22​=(x1​+x2​)2−2x1​x2​=25−12=13​

验证：方程两根为 x=2x=2x=2 和 x=3x=3x=3，22+32=4+9=132^2 + 3^2 = 4 + 9 = 1322+32=4+9=13 ✓

例题3（考研风格）：判别式确定参数范围

题目：若方程 x2+(k−2)x+k2−1=0x^2 + (k-2)x + k^2 - 1 = 0x2+(k−2)x+k2−1=0 有两个不等实根，求 kkk 的取值范围。

Δ=(k−2)2−4(k2−1)\Delta = (k-2)^2 - 4(k^2 - 1) Δ=(k−2)2−4(k2−1)

=k2−4k+4−4k2+4= k^2 - 4k + 4 - 4k^2 + 4 =k2−4k+4−4k2+4

即 3k2+4k−8<03k^2 + 4k - 8 < 03k2+4k−8<0

用求根公式解 3k2+4k−8=03k^2 + 4k - 8 = 03k2+4k−8=0：

例题4（考研风格）：韦达定理综合应用

题目：已知方程 x2−3x+1=0x^2 - 3x + 1 = 0x2−3x+1=0 的两根为 α,β\alpha, \betaα,β，求：

  1. α3+β3\alpha^3 + \beta^3α3+β3
  2. αβ+βα\dfrac{\alpha}{\beta} + \dfrac{\beta}{\alpha}βα​+αβ​

解：

由韦达定理：α+β=3\alpha + \beta = 3α+β=3，αβ=1\alpha\beta = 1αβ=1

第(1)问：

利用立方和公式：

α3+β3=(α+β)(α2−αβ+β2)\alpha^3 + \beta^3 = (\alpha + \beta)(\alpha^2 - \alpha\beta + \beta^2) α3+β3=(α+β)(α2−αβ+β2)

先算 α2+β2\alpha^2 + \beta^2α2+β2：

α2+β2=(α+β)2−2αβ=9−2=7\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = 9 - 2 = 7 α2+β2=(α+β)2−2αβ=9−2=7

代入：

α3+β3=3×(7−1)=3×6=18\alpha^3 + \beta^3 = 3 \times (7 - 1) = 3 \times 6 = \boxed{18} α3+β3=3×(7−1)=3×6=18​

第(2)问：

αβ+βα=α2+β2αβ=71=7\frac{\alpha}{\beta} + \frac{\beta}{\alpha} = \frac{\alpha^2 + \beta^2}{\alpha\beta} = \frac{7}{1} = \boxed{7} βα​+αβ​=αβα2+β2​=17​=7​

思路总结：这类题的核心思路是用韦达定理把所有表达式都转化成 (α+β)(\alpha + \beta)(α+β) 和 αβ\alpha\betaαβ 的组合，永远不需要真正求出根。

四、避坑指南

🚫 坑1：判别式忘了前提条件

判别式只对一元二次方程有效！用之前必须确认 a≠0a \neq 0a=0。

例：方程 ax2+2x+1=0ax^2 + 2x + 1 = 0ax2+2x+1=0 有实根 → 不能直接说 Δ≥0\Delta \geq 0Δ≥0，还要分 a=0a = 0a=0（变成一次方程，有根 x=−12x = -\frac{1}{2}x=−21​）和 a≠0a \neq 0a=0 两种情况讨论。

🚫 坑2：韦达定理符号搞反

和前面有负号：x1+x2=−bax_1 + x_2 = -\dfrac{b}{a}x1​+x2​=−ab​，不是 ba\dfrac{b}{a}ab​！

很多同学背成正号，丢分可惜。

🚫 坑3：题目说"两根"就认为有根

题目说"设 x1,x2x_1, x_2x1​,x2​ 是方程的两根"，暗含了 Δ≥0\Delta \geq 0Δ≥0 这个隐含条件。做题时别忘了验证！

🚫 坑4：1x1+1x2\frac{1}{x_1} + \frac{1}{x_2}x1​1​+x2​1​ 忘记 c≠0c \neq 0c=0

1x1+1x2=x1+x2x1x2=−bc\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1 x_2} = -\dfrac{b}{c}x1​1​+x2​1​=x1​x2​x1​+x2​​=−cb​，这个式子成立的前提是 x1x2≠0x_1 x_2 \neq 0x1​x2​=0，即 c≠0c \neq 0c=0。
