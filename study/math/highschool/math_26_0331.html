知识点概述

二次函数是高中数学的基础函数之一，形式为 y=ax2+bx+cy = ax^2 + bx + cy=ax2+bx+c（a≠0a \neq 0a=0）。其图像是一条抛物线，掌握图像性质是后续学习函数、不等式、最值问题的基础。

三种形式对比

  1. 一般式：y=ax2+bx+cy = ax^2 + bx + cy=ax2+bx+c — 直接读出 ccc（与 yyy 轴交点）
  2. 顶点式：y=a(x−h)2+ky = a(x - h)^2 + ky=a(x−h)2+k — 直接读出顶点 (h,k)(h, k)(h,k)
  3. 交点式：y=a(x−x1)(x−x2)y = a(x - x_1)(x - x_2)y=a(x−x1​)(x−x2​) — 直接读出与 xxx 轴交点

例题1（基础）：求抛物线的顶点和对称轴

题目：求 y=2x2−8x+5y = 2x^2 - 8x + 5y=2x2−8x+5 的顶点坐标和对称轴。

思路：

  1. 对称轴：x=−b2a=−−82×2=2x = -\dfrac{b}{2a} = -\dfrac{-8}{2 \times 2} = 2x=−2ab​=−2×2−8​=2
  2. 代入求纵坐标：y=2(2)2−8(2)+5=8−16+5=−3y = 2(2)^2 - 8(2) + 5 = 8 - 16 + 5 = -3y=2(2)2−8(2)+5=8−16+5=−3
  3. 顶点：(2,−3)(2, -3)(2,−3)，对称轴 x=2x = 2x=2

也可以用配方法验证：

y=2x2−8x+5=2(x2−4x)+5=2(x−2)2−8+5=2(x−2)2−3y = 2x^2 - 8x + 5 = 2(x^2 - 4x) + 5 = 2(x - 2)^2 - 8 + 5 = 2(x - 2)^2 - 3 y=2x2−8x+5=2(x2−4x)+5=2(x−2)2−8+5=2(x−2)2−3

例题2（进阶）：根据条件求二次函数

题目：已知抛物线过点 (1,0)(1, 0)(1,0)、(3,0)(3, 0)(3,0)，且顶点纵坐标为 −2-2−2，求解析式。

思路：

  1. 两个零点为 x1=1x_1 = 1x1​=1、x2=3x_2 = 3x2​=3，用交点式：y=a(x−1)(x−3)y = a(x - 1)(x - 3)y=a(x−1)(x−3)
  2. 对称轴 x=1+32=2x = \dfrac{1 + 3}{2} = 2x=21+3​=2，顶点 (2,−2)(2, -2)(2,−2)
  3. 代入顶点：−2=a(2−1)(2−3)=a×1×(−1)=−a-2 = a(2 - 1)(2 - 3) = a \times 1 \times (-1) = -a−2=a(2−1)(2−3)=a×1×(−1)=−a
  4. 所以 a=2a = 2a=2
  5. 解析式：y=2(x−1)(x−3)=2x2−8x+6y = 2(x - 1)(x - 3) = 2x^2 - 8x + 6y=2(x−1)(x−3)=2x2−8x+6

避坑指南

  1. a≠0a \neq 0a=0 别忘了：题目说"二次函数"就意味着 a≠0a \neq 0a=0，但含参问题中如果写的是 y=ax2+bx+cy = ax^2 + bx + cy=ax2+bx+c，要主动讨论 a=0a = 0a=0 的情况
  2. 配方法容易算错符号：b2/(4a)b^2/(4a)b2/(4a) 这一步最容易出错，建议配完方后代入验证
  3. 韦达定理的前提：必须 Δ≥0\Delta \geq 0Δ≥0 才能用！很多同学直接套用忘了判别式
  4. 区间最值三步走：找对称轴 → 判断与区间关系 → 分类讨论，缺一不可
  5. 图像平移方向：y=a(x−h)2+ky = a(x - h)^2 + ky=a(x−h)2+k 中，h>0h > 0h>0 是向右平移（括号里减才是右），和直觉相反
