0330 集合运算+逻辑联结词

知识点概述

集合

把某些确定的事物看成一个整体，这个整体就叫做集合，其中的事物叫做元素。

  • 集合的表示方法：列举法 {1,2,3}\{1,2,3\}{1,2,3}、描述法 {x∣x>0}\{x \mid x>0\}{x∣x>0}、区间法 (0,+∞)(0,+\infty)(0,+∞)
  • 常见集合：N\mathbb{N}N (自然数)、Z\mathbb{Z}Z (整数)、Q\mathbb{Q}Q (有理数)、R\mathbb{R}R (实数)

集合间的关系

  • 子集：A⊆BA \subseteq BA⊆B（AAA 的所有元素都在 BBB 中）
  • 真子集：A⊂BA \subset BA⊂B（A⊆BA \subseteq BA⊆B 且 A≠BA \neq BA=B）
  • 相等：A=BA = BA=B（A⊆BA \subseteq BA⊆B 且 B⊆AB \subseteq AB⊆A）

集合的运算

运算符号含义
并集A∪BA \cup BA∪B属于 AAA 或属于 BBB 的元素
交集A∩BA \cap BA∩B同时属于 AAA 和 BBB 的元素
补集∁UA\complement_U A∁U​A 或 A‾\overline{A}A全集 UUU 中不属于 AAA 的元素
差集A−BA - BA−B属于 AAA 但不属于 BBB 的元素

逻辑联结词

  • 且 (∧\wedge∧)：命题 PPP 且 QQQ 同时为真时为真
  • 或 (∨\vee∨)：命题 PPP 或 QQQ 至少一个为真时为真
  • 非 (¬\neg¬)：命题 PPP 的否定
  • 蕴含 (P⇒QP \Rightarrow QP⇒Q)：PPP 为真时 QQQ 必须为真
  • 等价 (P⇔QP \Leftrightarrow QP⇔Q)：P⇒QP \Rightarrow QP⇒Q 且 Q⇒PQ \Rightarrow PQ⇒P

核心公式

集合运算律

A∪B=B∪A（交换律）A \cup B = B \cup A \quad \text{（交换律）} A∪B=B∪A（交换律）

A∩B=B∩A（交换律）A \cap B = B \cap A \quad \text{（交换律）} A∩B=B∩A（交换律）

(A∪B)∪C=A∪(B∪C)（结合律）(A \cup B) \cup C = A \cup (B \cup C) \quad \text{（结合律）} (A∪B)∪C=A∪(B∪C)（结合律）

(A∩B)∩C=A∩(B∩C)（结合律）(A \cap B) \cap C = A \cap (B \cap C) \quad \text{（结合律）} (A∩B)∩C=A∩(B∩C)（结合律）

德摩根律（重点！）

A∪B‾=A‾∩B‾\overline{A \cup B} = \overline{A} \cap \overline{B} A∪B=A∩B

A∩B‾=A‾∪B‾\overline{A \cap B} = \overline{A} \cup \overline{B} A∩B=A∪B

记忆口诀：脱掉帽子要变号，"并"变"交"，"交"变"并"

集合与逻辑的对应

集合逻辑
并集 ∪\cup∪或 ∨\vee∨
交集 ∩\cap∩且 ∧\wedge∧
补集 A‾\overline{A}A非 ¬\neg¬

命题等价式

P⇒Q≡¬P∨QP \Rightarrow Q \equiv \neg P \vee Q P⇒Q≡¬P∨Q

P⇔Q≡(P⇒Q)∧(Q⇒P)P \Leftrightarrow Q \equiv (P \Rightarrow Q) \wedge (Q \Rightarrow P) P⇔Q≡(P⇒Q)∧(Q⇒P)

例题讲解

简单例题

例1：设 A={1,2,3}A = \{1,2,3\}A={1,2,3}，B={3,4,5}B = \{3,4,5\}B={3,4,5}，求 A∪BA \cup BA∪B、A∩BA \cap BA∩B、A−BA - BA−B。

解：

  • A∪B={1,2,3,4,5}A \cup B = \{1,2,3,4,5\}A∪B={1,2,3,4,5}（并集：合并所有元素）
  • A∩B={3}A \cap B = \{3\}A∩B={3}（交集：公共元素）
  • A−B={1,2}A - B = \{1,2\}A−B={1,2}（差集：属于 AAA 不属于 BBB）

考研风格例题

例2：已知全集 U={1,2,3,4,5,6}U = \{1,2,3,4,5,6\}U={1,2,3,4,5,6}，A={1,2,3}A = \{1,2,3\}A={1,2,3}，B={2,4,6}B = \{2,4,6\}B={2,4,6}。
求：(1) A∪B‾\overline{A \cup B}A∪B；(2) A‾∩B\overline{A} \cap BA∩B；(3) (A∩B‾)∪(B∩A‾)(A \cap \overline{B}) \cup (B \cap \overline{A})(A∩B)∪(B∩A)

解：

  • 先求并集：A∪B={1,2,3,4,6}A \cup B = \{1,2,3,4,6\}A∪B={1,2,3,4,6}
  • (1) A∪B‾=U−(A∪B)={5}\overline{A \cup B} = U - (A \cup B) = \{5\}A∪B=U−(A∪B)={5}
  • (2) A‾={4,5,6}\overline{A} = \{4,5,6\}A={4,5,6}，所以 A‾∩B={4,6}\overline{A} \cap B = \{4,6\}A∩B={4,6}
  • (3) B‾={1,3,5}\overline{B} = \{1,3,5\}B={1,3,5}，A∩B‾={1,3}A \cap \overline{B} = \{1,3\}A∩B={1,3}
    A‾={4,5,6}\overline{A} = \{4,5,6\}A={4,5,6}，B∩A‾={4,6}B \cap \overline{A} = \{4,6\}B∩A={4,6}
    所以 (A∩B‾)∪(B∩A‾)={1,3,4,6}(A \cap \overline{B}) \cup (B \cap \overline{A}) = \{1,3,4,6\}(A∩B)∪(B∩A)={1,3,4,6}

解题思路：

  1. 遇到补集先画韦恩图辅助分析
  2. 复杂运算先拆分，每步单独计算
  3. 利用德摩根律简化计算

例3：判断命题"若 x2>4x^2 > 4x2>4，则 x>2x > 2x>2"的真假，并写出其逆命题、否命题、逆否命题。

解：
原命题：P:x2>4P: x^2 > 4P:x2>4，Q:x>2Q: x > 2Q:x>2

原命题为假（反例：x=−3x = -3x=−3，(−3)2=9>4(-3)^2 = 9 > 4(−3)2=9>4 但 −3<2-3 < 2−3<2）

  • 逆命题：若 x>2x > 2x>2，则 x2>4x^2 > 4x2>4（真）
  • 否命题：若 x2≤4x^2 \leq 4x2≤4，则 x≤2x \leq 2x≤2（假，反例：x=−3x = -3x=−3）
  • 逆否命题：若 x≤2x \leq 2x≤2，则 x2≤4x^2 \leq 4x2≤4（真，原命题与逆否命题同真同假）

避坑指南

  1. 混淆 ∈\in∈ 和 ⊆\subseteq⊆

    • 1∈{1,2}1 \in \{1,2\}1∈{1,2} 表示"1是集合的元素"
    • {1}⊆{1,2}\{1\} \subseteq \{1,2\}{1}⊆{1,2} 表示"{1}是集合的子集"
    • 易错：{1}∈{1,2}\{1\} \in \{1,2\}{1}∈{1,2} 是错误的！

  2. 空集是任意集合的子集

    • ∅⊆A\varnothing \subseteq A∅⊆A 永远成立
    • ∅∈A\varnothing \in A∅∈A 不一定成立

  3. 德摩根律记反

    • 并的补 = 交的补
    • 交的补 = 并的补
    • 检验方法：取特殊值验证

  4. 忽略全集

    • 求补集时必须明确全集 UUU
    • 不同全集下同一集合的补集不同

  5. 命题等价式易错

    • P⇒QP \Rightarrow QP⇒Q 的否定是 P∧¬QP \wedge \neg QP∧¬Q
    • 不要写成 ¬P⇒¬Q\neg P \Rightarrow \neg Q¬P⇒¬Q

  6. "或"与"且"的混淆

    • A∪BA \cup BA∪B：至少属于其中一个（兼容并蓄）
    • A∩BA \cap BA∩B ：必须同时属于两个（双重标准）
