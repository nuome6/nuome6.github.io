19.1 函数

变量与函数

常量： 在变化过程中数值不变的量
变量： 在变化过程中数值变化的量

函数定义： 在一个变化过程中，如果有两个变量 xxx、yyy，对于 xxx 的每一个确定的值，yyy 都有唯一确定的值与之对应，那么 xxx 是自变量，yyy 是 xxx 的函数。

函数三要素：

  1. 定义域（自变量的取值范围）
  2. 对应关系
  3. 值域

自变量取值范围：

  • 整式函数：全体实数
  • 分式函数：分母 ≠ 0
  • 根式函数：被开方数 ≥ 0
  • 实际问题：符合实际意义

函数的图象

表示方法：

  1. 解析式法（公式）
  2. 列表法
  3. 图象法

画图象步骤：

  1. 列表（取若干个自变量的值）
  2. 描点
  3. 连线（用平滑曲线）

19.2 一次函数

19.2.1 正比例函数

定义： y=kxy = kxy=kx（k≠0k \neq 0k=0）

图象： 过原点 (0,0)(0, 0)(0,0) 的直线

性质：

  • k>0k > 0k>0：图象过一、三象限，yyy 随 xxx 增大而增大（上升）
  • k<0k < 0k<0：图象过二、四象限，yyy 随 xxx 增大而减小（下降）

19.2.2 一次函数

定义： y=kx+by = kx + by=kx+b（k≠0k \neq 0k=0）

  • b=0b = 0b=0 时就是正比例函数
  • kkk 决定斜率（倾斜程度）
  • bbb 决定 y 轴截距（与 y 轴交点的纵坐标）

图象： 一条直线

kkkbbb图象位置
k>0k > 0k>0b>0b > 0b>0一、二、三象限
k>0k > 0k>0b<0b < 0b<0一、三、四象限
k<0k < 0k<0b>0b > 0b>0一、二、四象限
k<0k < 0k<0b<0b < 0b<0二、三、四象限

性质：

  • k>0k > 0k>0：yyy 随 xxx 增大而增大
  • k<0k < 0k<0：yyy 随 xxx 增大而减小

待定系数法求解析式

步骤：

  1. 设解析式为 y=kx+by = kx + by=kx+b
  2. 代入已知点的坐标
  3. 解方程组求 kkk、bbb

例： 图象过点 (1,3)(1, 3)(1,3) 和 (3,7)(3, 7)(3,7)，求解析式

  • 代入：{k+b=33k+b=7\begin{cases} k + b = 3 \\ 3k + b = 7 \end{cases}{k+b=33k+b=7​
  • 解得：k=2,b=1k = 2, b = 1k=2,b=1
  • y=2x+1y = 2x + 1y=2x+1

19.2.3 一次函数与方程、不等式

与一元一次方程的关系

y=kx+b=0y = kx + b = 0y=kx+b=0 的解，就是图象与 x 轴交点的横坐标

x=−bkx = -\frac{b}{k} x=−kb​

与一元一次不等式的关系

  • kx+b>0kx + b > 0kx+b>0：图象在 x 轴上方的部分对应的 xxx 范围
  • kx+b<0kx + b < 0kx+b<0：图象在 x 轴下方的部分对应的 xxx 范围

与二元一次方程组的关系

两直线的交点坐标就是方程组的解

例：

{y=2x+1y=−x+4\begin{cases} y = 2x + 1 \\ y = -x + 4 \end{cases} {y=2x+1y=−x+4​

交点：(1,3)(1, 3)(1,3)，即 x=1,y=3x = 1, y = 3x=1,y=3

综合例题

例1： 一次函数过 (0,−2)(0, -2)(0,−2) 和 (3,4)(3, 4)(3,4)，求解析式

  • b=−2b = -2b=−2
  • 3k−2=43k - 2 = 43k−2=4 → k=2k = 2k=2
  • y=2x−2y = 2x - 2y=2x−2

例2： y=3x−6y = 3x - 6y=3x−6，当 xxx 为何值时 y>0y > 0y>0？

  • 3x−6>03x - 6 > 03x−6>0
  • x>2x > 2x>2

考研相关

一次函数在考研中是微积分的起点：

  • 一次函数 = 最简单的函数
  • 斜率 kkk = 导数的前身概念
  • 图象分析 = 单调性判断的基础
  • 直线方程 = 解析几何的基础
