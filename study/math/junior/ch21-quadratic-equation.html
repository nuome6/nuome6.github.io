一元二次方程

人教版九年级上册 · 第二十一章

一、知识点概述

一元二次方程是初中数学的重要内容，也是高中数学和考研数学的基础。本章学习一元二次方程的概念、解法和应用。

核心主线：

概念→解法→应用\text{概念} \rightarrow \text{解法} \rightarrow \text{应用} 概念→解法→应用

  • 概念：什么是一元二次方程？它的一般形式是什么？
  • 解法：配方法、公式法、因式分解法
  • 应用：用一元二次方程解决实际问题

二、核心概念与公式

2.1 一元二次方程的定义

定义： 只含有一个未知数（一元），并且未知数的最高次数是 2（二次）的整式方程，叫做一元二次方程。

一般形式：

ax2+bx+c=0(a≠0)ax^2 + bx + c = 0 \quad (a \neq 0) ax2+bx+c=0(a=0)

其中：

  • aaa 是二次项系数
  • bbb 是一次项系数
  • ccc 是常数项

关键条件

a≠0a \neq 0a=0 是一元二次方程的必要条件！如果 a=0a = 0a=0，方程就变成一次方程了。

判断方法： 看一个方程是不是一元二次方程，需要满足三个条件：

  1. 整式方程（分母里不能有未知数）
  2. 一个未知数
  3. 最高次数是 2

2.2 解法一：直接开平方法

适用情况： 方程形如 x2=px^2 = px2=p 或 (x+m)2=p(x + m)^2 = p(x+m)2=p（p≥0p \geq 0p≥0）

方法：

x2=p⇒x=±px^2 = p \Rightarrow x = \pm\sqrt{p} x2=p⇒x=±p​

例： 解方程 x2=9x^2 = 9x2=9

x=±9=±3x = \pm\sqrt{9} = \pm 3 x=±9​=±3

所以 x1=3x_1 = 3x1​=3，x2=−3x_2 = -3x2​=−3

2.3 解法二：配方法

核心思想： 把方程转化为 (x+m)2=p(x + m)^2 = p(x+m)2=p 的形式，再用开平方法。

步骤：

  1. 移项：把常数项移到右边
  2. 二次项系数化为 1
  3. 配方：两边同时加上一次项系数一半的平方
  4. 写成完全平方形式
  5. 开平方法求解

完全平方公式

(a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2 (a+b)2=a2+2ab+b2

(a−b)2=a2−2ab+b2(a - b)^2 = a^2 - 2ab + b^2 (a−b)2=a2−2ab+b2

配方时，需要加上的数 = (b2)2\left(\dfrac{b}{2}\right)^2(2b​)2

2.4 解法三：公式法（最重要！）

求根公式： 对于 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0（a≠0a \neq 0a=0），当 b2−4ac≥0b^2 - 4ac \geq 0b2−4ac≥0 时：

x=−b±b2−4ac2ax = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} x=2a−b±b2−4ac​​

其中 b2−4acb^2 - 4acb2−4ac 叫做判别式，用 Δ\DeltaΔ 表示：

Δ=b2−4ac\Delta = b^2 - 4ac Δ=b2−4ac

判别式的作用

  • Δ>0\Delta > 0Δ>0：方程有两个不相等的实数根
  • Δ=0\Delta = 0Δ=0：方程有两个相等的实数根（重根）
  • Δ<0\Delta < 0Δ<0：方程没有实数根

2.5 解法四：因式分解法

核心思想： 把方程左边分解成两个因式的乘积，令每个因式等于 0。

常用方法：

  • 提公因式法： ax2+bx=x(ax+b)ax^2 + bx = x(ax + b)ax2+bx=x(ax+b)
  • 公式法： a2−b2=(a+b)(a−b)a^2 - b^2 = (a+b)(a-b)a2−b2=(a+b)(a−b)
  • 十字相乘法： x2+(p+q)x+pq=(x+p)(x+q)x^2 + (p+q)x + pq = (x+p)(x+q)x2+(p+q)x+pq=(x+p)(x+q)

2.6 根与系数的关系（韦达定理）

如果 x1x_1x1​、x2x_2x2​ 是方程 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 的两个根，则：

x1+x2=−bax_1 + x_2 = -\frac{b}{a} x1​+x2​=−ab​

x1⋅x2=cax_1 \cdot x_2 = \frac{c}{a} x1​⋅x2​=ac​

韦达定理的应用

  • 已知两根，求原方程
  • 已知一根，求另一根
  • 求关于两根的代数式的值（如 x12+x22x_1^2 + x_2^2x12​+x22​）

三、例题讲解

例1（基础）判断是否为一元二次方程

判断下列方程是否为一元二次方程：
(1) x2+2x=x2−1x^2 + 2x = x^2 - 1x2+2x=x2−1
(2) ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0
(3) 1x2+2x=1\frac{1}{x^2} + 2x = 1x21​+2x=1

解析：

(1) 整理：x2+2x=x2−1⇒2x+1=0x^2 + 2x = x^2 - 1 \Rightarrow 2x + 1 = 0x2+2x=x2−1⇒2x+1=0

这是一元一次方程，不是一元二次方程。

(2) 需要 a≠0a \neq 0a=0 才是一元二次方程。如果 a=0a = 0a=0，就不是。

(3) 分母含有未知数，是分式方程，不是整式方程，所以不是一元二次方程。

例2（基础）用配方法解方程

解方程：x2+6x+5=0x^2 + 6x + 5 = 0x2+6x+5=0

解析：

第一步：移项

x2+6x=−5x^2 + 6x = -5 x2+6x=−5

第二步：配方（两边加 (62)2=9\left(\frac{6}{2}\right)^2 = 9(26​)2=9）

x2+6x+9=−5+9x^2 + 6x + 9 = -5 + 9 x2+6x+9=−5+9

第三步：写成完全平方

(x+3)2=4(x + 3)^2 = 4 (x+3)2=4

第四步：开平方

x+3=±2x + 3 = \pm 2 x+3=±2

所以 x1=−1x_1 = -1x1​=−1，x2=−5x_2 = -5x2​=−5

例3（基础）用公式法解方程

解方程：2x2−5x+3=02x^2 - 5x + 3 = 02x2−5x+3=0

解析：

这里 a=2a = 2a=2，b=−5b = -5b=−5，c=3c = 3c=3

先算判别式：

Δ=b2−4ac=(−5)2−4×2×3=25−24=1>0\Delta = b^2 - 4ac = (-5)^2 - 4 \times 2 \times 3 = 25 - 24 = 1 > 0 Δ=b2−4ac=(−5)2−4×2×3=25−24=1>0

代入求根公式：

x=−(−5)±12×2=5±14x = \frac{-(-5) \pm \sqrt{1}}{2 \times 2} = \frac{5 \pm 1}{4} x=2×2−(−5)±1​​=45±1​

所以 x1=64=32x_1 = \frac{6}{4} = \frac{3}{2}x1​=46​=23​，x2=44=1x_2 = \frac{4}{4} = 1x2​=44​=1

例4（基础）用因式分解法解方程

解方程：x2−5x+6=0x^2 - 5x + 6 = 0x2−5x+6=0

解析：

十字相乘：

x2−5x+6=(x−2)(x−3)=0x^2 - 5x + 6 = (x - 2)(x - 3) = 0 x2−5x+6=(x−2)(x−3)=0

所以 x−2=0x - 2 = 0x−2=0 或 x−3=0x - 3 = 0x−3=0

x1=2x_1 = 2x1​=2，x2=3x_2 = 3x2​=3

例5（进阶）韦达定理应用

已知方程 x2−3x+m=0x^2 - 3x + m = 0x2−3x+m=0 的一个根是 x1=1x_1 = 1x1​=1，求另一个根和 mmm 的值。

解析：

方法一：代入法

把 x1=1x_1 = 1x1​=1 代入方程：

12−3×1+m=0⇒1−3+m=0⇒m=21^2 - 3 \times 1 + m = 0 \Rightarrow 1 - 3 + m = 0 \Rightarrow m = 2 12−3×1+m=0⇒1−3+m=0⇒m=2

方程变为 x2−3x+2=0x^2 - 3x + 2 = 0x2−3x+2=0，即 (x−1)(x−2)=0(x-1)(x-2) = 0(x−1)(x−2)=0

所以 x2=2x_2 = 2x2​=2

方法二：韦达定理

x1+x2=3⇒1+x2=3⇒x2=2x_1 + x_2 = 3 \Rightarrow 1 + x_2 = 3 \Rightarrow x_2 = 2 x1​+x2​=3⇒1+x2​=3⇒x2​=2

x1⋅x2=m⇒1×2=m⇒m=2x_1 \cdot x_2 = m \Rightarrow 1 \times 2 = m \Rightarrow m = 2 x1​⋅x2​=m⇒1×2=m⇒m=2

例6（考研风格）含参数的方程

若关于 xxx 的方程 kx2−6x+9=0kx^2 - 6x + 9 = 0kx2−6x+9=0 有两个不相等的实数根，求 kkk 的取值范围。

解析：

要使方程有两个不相等的实数根，需要满足：

① 是一元二次方程：k≠0k \neq 0k=0

② 判别式大于 0：

Δ=(−6)2−4×k×9>0\Delta = (-6)^2 - 4 \times k \times 9 > 0 Δ=(−6)2−4×k×9>0

36−36k>036 - 36k > 0 36−36k>0

k<1k < 1 k<1

综合 ①②：k<1k < 1k<1 且 k≠0k \neq 0k=0

答案： k<1k < 1k<1 且 k≠0k \neq 0k=0

四、避坑指南

❌ 坑1：忘记 a≠0a \neq 0a=0 的条件

题目说"关于 xxx 的方程 (m−1)x2+3x−2=0(m-1)x^2 + 3x - 2 = 0(m−1)x2+3x−2=0 是一元二次方程"，则 m≠1m \neq 1m=1。

❌ 坑2：配方法漏加常数

配方时，左边加了 (b2)2\left(\frac{b}{2}\right)^2(2b​)2，右边也要加！

❌ 坑3：公式法代错符号

x=−b±b2−4ac2ax = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} x=2a−b±b2−4ac​​

注意 −b-b−b 的符号！如果 b=−3b = -3b=−3，则 −b=3-b = 3−b=3。

❌ 坑4：判别式 Δ\DeltaΔ 算错

Δ=b2−4ac\Delta = b^2 - 4ac Δ=b2−4ac

注意是 b2b^2b2，不是 (2b)2(2b)^2(2b)2 或 2b22b^22b2。

❌ 坑5：因式分解法漏解

(x−2)(x−3)=0(x-2)(x-3) = 0(x−2)(x−3)=0 的解是 x=2x = 2x=2 或 x=3x = 3x=3，不要漏掉任何一个！

✅ 解法选择口诀

  1. 能因式分解 → 因式分解法（最快）
  2. 不能分解但简单 → 配方法
  3. 一般情况 → 公式法（万能）
  4. 形如 x2=px^2 = px2=p → 直接开平方法
