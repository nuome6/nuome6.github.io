初中代数基础知识点（考研数学二前置）

初中代数基础知识点（考研数学二前置）

适用人群：中职/初中水平，准备考研数学二
目标：掌握代数基本运算，无障碍进入高中+考研数学
核心要求：公式背熟 + 计算熟练

一、整式运算

1.1 幂的运算（必须背熟）

am×an=am+n（同底数幂相乘，指数相加）a^m \times a^n = a^{m+n} \quad \text{（同底数幂相乘，指数相加）} am×an=am+n（同底数幂相乘，指数相加）

am÷an=am−n（同底数幂相除，指数相减）a^m \div a^n = a^{m-n} \quad \text{（同底数幂相除，指数相减）} am÷an=am−n（同底数幂相除，指数相减）

(am)n=amn（幂的乘方，指数相乘）(a^m)^n = a^{mn} \quad \text{（幂的乘方，指数相乘）} (am)n=amn（幂的乘方，指数相乘）

(ab)n=anbn（积的乘方，各自乘方）(ab)^n = a^n b^n \quad \text{（积的乘方，各自乘方）} (ab)n=anbn（积的乘方，各自乘方）

a0=1 (a≠0),a−n=1ana^0 = 1 \ (a \neq 0), \quad a^{-n} = \frac{1}{a^n} a0=1 (a=0),a−n=an1​

1.2 乘法公式（必须背熟！）⭐⭐⭐

平方差公式：

(a+b)(a−b)=a2−b2(a+b)(a-b) = a^2 - b^2 (a+b)(a−b)=a2−b2

例：(x+5)(x−5)=x2−25(x+5)(x-5) = x^2 - 25(x+5)(x−5)=x2−25

完全平方公式：

(a+b)2=a2+2ab+b2(a+b)^2 = a^2 + 2ab + b^2 (a+b)2=a2+2ab+b2

(a−b)2=a2−2ab+b2(a-b)^2 = a^2 - 2ab + b^2 (a−b)2=a2−2ab+b2

例：(x+3)2=x2+6x+9(x+3)^2 = x^2 + 6x + 9(x+3)2=x2+6x+9

⚠️ 常见错误： (a+b)2≠a2+b2(a+b)^2 \neq a^2 + b^2(a+b)2=a2+b2（漏掉中间项 2ab2ab2ab）

1.3 因式分解 ⭐⭐⭐ 最重要

因式分解 = 乘法公式的逆运算

方法一：提公因式法

6x2+9x=3x(2x+3)6x^2 + 9x = 3x(2x + 3) 6x2+9x=3x(2x+3)

方法二：公式法

x2−9=(x+3)(x−3)（平方差）x^2 - 9 = (x+3)(x-3) \quad \text{（平方差）} x2−9=(x+3)(x−3)（平方差）

x2+6x+9=(x+3)2（完全平方）x^2 + 6x + 9 = (x+3)^2 \quad \text{（完全平方）} x2+6x+9=(x+3)2（完全平方）

方法三：十字相乘法 ⭐⭐⭐ 考研最常用

x2+(a+b)x+ab=(x+a)(x+b)x^2 + (a+b)x + ab = (x+a)(x+b) x2+(a+b)x+ab=(x+a)(x+b)

  • 例：x2+5x+6=(x+2)(x+3)x^2 + 5x + 6 = (x+2)(x+3)x2+5x+6=(x+2)(x+3)（因为 2+3=52+3=52+3=5，2×3=62 \times 3=62×3=6）
  • 例：x2−7x+12=(x−3)(x−4)x^2 - 7x + 12 = (x-3)(x-4)x2−7x+12=(x−3)(x−4)
  • 例：x2+2x−8=(x+4)(x−2)x^2 + 2x - 8 = (x+4)(x-2)x2+2x−8=(x+4)(x−2)

十字相乘法口诀：

  • 先看常数项的因数对
  • 找哪一对的和等于一次项系数
  • 常数项为正 → 两因数同号（看一次项定正负）
  • 常数项为负 → 两因数异号

二、分式运算

2.1 分式的基本性质

AB=A×MB×M=A÷MB÷M(M≠0)\frac{A}{B} = \frac{A \times M}{B \times M} = \frac{A \div M}{B \div M} \quad (M \neq 0) BA​=B×MA×M​=B÷MA÷M​(M=0)

2.2 分式运算

同分母加减：

ac±bc=a±bc\frac{a}{c} \pm \frac{b}{c} = \frac{a \pm b}{c} ca​±cb​=ca±b​

异分母加减（先通分）：

ab±cd=ad±bcbd\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd} ba​±dc​=bdad±bc​

例：

1x−1+1x+1=(x+1)+(x−1)(x−1)(x+1)=2xx2−1\frac{1}{x-1} + \frac{1}{x+1} = \frac{(x+1)+(x-1)}{(x-1)(x+1)} = \frac{2x}{x^2-1} x−11​+x+11​=(x−1)(x+1)(x+1)+(x−1)​=x2−12x​

乘除法：

ab×cd=acbd,ab÷cd=ab×dc=adbc\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}, \quad \frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{ad}{bc} ba​×dc​=bdac​,ba​÷dc​=ba​×cd​=bcad​

三、方程

3.1 一元二次方程 ⭐⭐⭐

标准形式： ax2+bx+c=0(a≠0)ax^2 + bx + c = 0 \quad (a \neq 0)ax2+bx+c=0(a=0)

求根公式 ⭐⭐⭐：

x=−b±b2−4ac2ax = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} x=2a−b±b2−4ac​​

判别式 Δ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac ⭐⭐⭐：

Δ>0⇒两个不相等的实数根\Delta > 0 \Rightarrow \text{两个不相等的实数根} Δ>0⇒两个不相等的实数根

Δ=0⇒两个相等的实数根\Delta = 0 \Rightarrow \text{两个相等的实数根} Δ=0⇒两个相等的实数根

Δ<0⇒没有实数根\Delta < 0 \Rightarrow \text{没有实数根} Δ<0⇒没有实数根

韦达定理 ⭐⭐⭐：

若 x1,x2x_1, x_2x1​,x2​ 是 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 的两根，则：

x1+x2=−ba,x1⋅x2=cax_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a} x1​+x2​=−ab​,x1​⋅x2​=ac​

例：x2−5x+6=0x^2 - 5x + 6 = 0x2−5x+6=0，两根之和 =5= 5=5，两根之积 =6= 6=6（验证：2+3=52+3=52+3=5，2×3=62 \times 3=62×3=6 ✅）
