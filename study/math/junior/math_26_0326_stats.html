20.1 数据的集中趋势

20.1.1 平均数

算术平均数：

xˉ=x1+x2+⋯+xnn\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n} xˉ=nx1​+x2​+⋯+xn​​

加权平均数：

xˉ=x1f1+x2f2+⋯+xkfkf1+f2+⋯+fk\bar{x} = \frac{x_1 f_1 + x_2 f_2 + \cdots + x_k f_k}{f_1 + f_2 + \cdots + f_k} xˉ=f1​+f2​+⋯+fk​x1​f1​+x2​f2​+⋯+xk​fk​​

其中 fif_ifi​ 是 xix_ixi​ 出现的次数（权重）

例： 5个数据中有3个是8，2个是12，求平均数

xˉ=8×3+12×25=485=9.6\bar{x} = \frac{8 \times 3 + 12 \times 2}{5} = \frac{48}{5} = 9.6 xˉ=58×3+12×2​=548​=9.6

性质：

  • 每个数据都对平均数有影响
  • 极端值（特别大或特别小）会拉高/拉低平均数
  • 平均数是最常用的集中趋势指标

20.1.2 中位数和众数

中位数： 将数据从小到大排列后，位于中间位置的数

  • 数据个数 nnn 为奇数：第 n+12\frac{n+1}{2}2n+1​ 个
  • 数据个数 nnn 为偶数：中间两个数的平均值

例： 3, 5, 7, 9, 11 → 中位数是第3个 = 7
例： 3, 5, 7, 9 → 中位数是 5+72\frac{5+7}{2}25+7​ = 6

众数： 出现次数最多的数据

  • 可能没有众数（每个数据出现次数相同）
  • 可能有多个众数

例： 1, 2, 2, 3, 3, 4 → 众数是 2 和 3

三者对比

指标优点缺点
平均数利用全部数据，最灵敏受极端值影响大
中位数不受极端值影响不能充分利用所有数据
众数直观反映最多情况可能不唯一或不存在

20.2 数据的波动程度（方差）

方差公式

S2=1n[(x1−xˉ)2+(x2−xˉ)2+⋯+(xn−xˉ)2]S^2 = \frac{1}{n} \left[ (x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \cdots + (x_n - \bar{x})^2 \right] S2=n1​[(x1​−xˉ)2+(x2​−xˉ)2+⋯+(xn​−xˉ)2]

方差越小 → 数据越稳定、波动越小
方差越大 → 数据越不稳定、波动越大

例题

两组数据：A 组 = 2, 4, 6；B 组 = 1, 4, 7

两组的平均数都是 4

  • A 组方差：(2−4)2+(4−4)2+(6−4)23=83\frac{(2-4)^2 + (4-4)^2 + (6-4)^2}{3} = \frac{8}{3}3(2−4)2+(4−4)2+(6−4)2​=38​
  • B 组方差：(1−4)2+(4−4)2+(7−4)23=183=6\frac{(1-4)^2 + (4-4)^2 + (7-4)^2}{3} = \frac{18}{3} = 63(1−4)2+(4−4)2+(7−4)2​=318​=6

A 组方差更小，数据更稳定

标准差

S=S2S = \sqrt{S^2} S=S2​

标准差与原数据单位相同，更直观

综合例题

例： 一组数据 3, 7, 5, xxx, 9，平均数是 6，求 xxx 和方差

  • 平均数 = 6 → 3+7+5+x+9=303 + 7 + 5 + x + 9 = 303+7+5+x+9=30 → x=6x = 6x=6
  • 方差 =(3−6)2+(7−6)2+(5−6)2+(6−6)2+(9−6)25=9+1+1+0+95=4= \frac{(3-6)^2 + (7-6)^2 + (5-6)^2 + (6-6)^2 + (9-6)^2}{5} = \frac{9+1+1+0+9}{5} = 4=5(3−6)2+(7−6)2+(5−6)2+(6−6)2+(9−6)2​=59+1+1+0+9​=4

考研相关

统计学在考研中主要出现在：

  • 概率论：期望（加权平均数）、方差
  • 数理统计：样本均值、样本方差
  • 线性代数：均值向量
