📐 初中数学兜底 - 分式、方程与不等式

日期：2026-03-25 | 阶段：初中核心基础兜底

一、分式

基本概念

  • 分式：形如 A/B，B≠0
  • 最简分式：分子分母没有公因式

分式运算

  • 通分：找最小公倍数
  • 约分：分子分母同除公因式
  • 加减：先通分，再加减
  • 乘除：直接乘/除

二、一元二次方程 ax² + bx + c = 0 (a≠0)

判别式 Δ = b² - 4ac

  • Δ > 0 → 两个不相等实根
  • Δ = 0 → 两个相等实根（重根）
  • Δ < 0 → 无实根（有共轭复根）

求根公式

x=−b±b2−4ac2ax = \frac{-b ± \sqrt{b^2-4ac}}{2a} x=2a−b±b2−4ac​​

韦达定理（根与系数的关系）

  • x1+x2=−bax_1 + x_2 = -\frac{b}{a}x1​+x2​=−ab​
  • x1⋅x2=cax_1 \cdot x_2 = \frac{c}{a}x1​⋅x2​=ac​

韦达定理逆用（构造方程）

已知两根 x1,x2x_1, x_2x1​,x2​，构造方程：

x2−(x1+x2)x+x1x2=0x^2 - (x_1+x_2)x + x_1x_2 = 0 x2−(x1​+x2​)x+x1​x2​=0

例：根为 2 和 3 → x2−5x+6=0x^2 - 5x + 6 = 0x2−5x+6=0

例题

  • Δ = 25 - 24 = 1 > 0
  • x=5±12x = \frac{5±1}{2}x=25±1​ → x1=3,x2=2x_1=3, x_2=2x1​=3,x2​=2
  • 验证：3+2=5 ✓，3×2=6 ✓

三、不等式

一元一次不等式 ax + b > 0

  • 解：x>−bax > -\frac{b}{a}x>−ab​
  • ⚠️ a < 0 时不等号方向反向！

一元二次不等式 ax² + bx + c > 0 (a > 0)

  1. 先求方程两根 x1,x2x_1, x_2x1​,x2​

  2. 0：取两头，x<x1x < x_1x<x1​ 或 x>x2x > x_2x>x2​

  3. < 0：夹中间，x1<x<x2x_1 < x < x_2x1​<x<x2​

例： x2−5x+6>0x^2-5x+6 > 0x2−5x+6>0，根为 2 和 3，开口向上

  • 解集：x<2x < 2x<2 或 x>3x > 3x>3

无实根时的结论

  • ax2+bx+c>0ax^2+bx+c > 0ax2+bx+c>0 (a > 0)：解集为 R（恒成立）
  • ax2+bx+c<0ax^2+bx+c < 0ax2+bx+c<0 (a > 0)：解集为 ∅（恒不成立）

⚠️ 易错提醒

  • 用求根公式前先确认 a ≠ 0
  • a < 0 时不等号方向要反向
  • 韦达定理只对有实根的情况适用
  • 无实根时 Δ < 0 的不等式判断不要忘
