2.3.1 单链表的定义

对应视频 P12 | 2026-03-25

概念

单链表是一种链式存储的线性表，每个结点存放数据元素和指向后继的指针。

代码

// 单链表结点定义
typedef struct LNode {
    int data;           // 数据域
    struct LNode *next; // 指针域
} LNode, *LinkList;

// 头节点：第1个结点前的哨兵结点，简化插入删除操作
// 头指针：指向头节点的指针（或指向第1个结点的指针）

注意事项

  • 头节点的 data 不存储有效数据（或存放表长等信息）
  • 判断空表：L->next == NULL
  • 头节点让所有位置的插入删除操作统一
