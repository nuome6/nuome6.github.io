阶段 2：HTTP 和"接口"到底是什么 —— 2 晚

这阶段纯概念，不写代码，但答辩那三个"关键问题"能不能讲圆，全看这里有没有通。

内容类比
请求 / 响应 · 【必会】你去柜台报单号，柜员给你一张纸
URL 与查询参数 ?ids=1,2&brand=华为 · 【必会】报单号时补充"我要这两台"。对比页就是靠地址栏决定内容的
JSON · 【必会】那张纸的格式
状态码 200 / 400 / 404 / 500 · 【必会】400 你报的东西不合格、404 查无此项、500 柜台自己崩了
状态码 401 / 403 · 【看得懂】没登录 / 登录了但没权限。后台接口都靠它挡
浏览器 F12 → Network 面板 · 【必会】答辩演示杀手锏：现场点一下，展示"页面确实向后端发了请求"
校验要做在后端，前端那道挡不住 · 【必会】直接在地址栏敲 ids=1,999 就绕过前端了。这是能讲"我考虑过安全"的地方
跨域 CORS · 【看得懂】开发时前端 5173、后端 8000 才需要；上线后同一个地址，用不上了。知道它长什么样就行
RESTful · 【必会，一句话就够】URL 表示"什么东西"，动词（GET/POST/PUT/DELETE）表示"对它做啥"

过关检验：在浏览器地址栏手动把 ?ids=1,2 改成 ?ids=1,2,3，看页面变不变；
再改成 ?ids=1,999，看后端回的那句中文拒绝理由。

阶段 3：Python 够用的部分 —— 1 周

  • 缩进就是 {}、def、return 【必会】
  • 列表 []、字典 {}、for x in 【必会】
  • import 【必会】
  • f-string 拼字符串 【必会】
  • 函数参数默认值 【必会】
  • with ... as（用完自动关门）【看得懂】 —— 数据层的每个数据库连接都是这么写的
  • 类 class（只要能看懂 Store 那几个方法）【看得懂】
  • 装饰器 @ 的原理 【别学】 —— 但要知道 @app.get(...) 是"把下面这个函数登记成一个网址"，这一句必须会解释
  • 生成器、多线程、元类 【别学】

过关检验：在 demo/step1/main.py 的手机数据里加第三台，页面能显示出来。

阶段 4：FastAPI 的四个套路 —— 1 周

内容备注
写一个 @app.get("/api/phones") 返回 JSON · 【必会】
查询参数怎么接（函数签名上的参数名自动对应） · 【必会】
路径参数 /api/phones/{pid} · 【必会】
报错要说人话：HTTPException(400, detail="请选 2 到 5 台机型对比") · 【必会】项目里所有拒绝都是中文的，答辩时当场念一句给老师听
这个接口需要登录才能碰（依赖注入 Depends） · 【看得懂】知道"后台接口每个都挂了一道门"就够，不必会写
Pydantic 模型 · 【看得懂】当"参数格式校验表"理解就够
/docs 自动生成的接口页 · 【必会，且答辩必演示】这是选 FastAPI 最大的红利，白送的
Uvicorn 是什么 · 【看得懂】一个"把 Python 程序变成能访问的网站"的启动器

过关检验：自己加一个 /api/hello 接口，返回一句话，http://localhost:8000/docs 里能看到它、能点它。
