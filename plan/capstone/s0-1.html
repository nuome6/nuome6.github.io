动手之前（阶段 0—1）

Nuouo2026/9/24大约 2 分钟

动手之前

阶段 0：先打通"我改了，怎么让它生效" —— 1 晚【最先做，比学什么都优先】

这一环原清单完全没有，而它是现在必然会撞上的第一堵墙：
你改了页面文件，刷新，什么都没变——你会以为改动没生效，其实是你没跑那一步构建。

内容一句话解释
frontend/src/ 里的东西不是浏览器看到的东西 · 【必会】中间要过一道 pnpm build，产物在 frontend/dist/，http://localhost:8000 发的是 dist
改了 .vue 或 .css 之后要做什么 · 【必会】cd frontend && pnpm build，然后回浏览器 Ctrl+F5
改了 .py 之后要做什么 · 【必会】重启那个标题叫"毕设-后端API"的窗口里的程序（Ctrl+C 停，再启动）
后端还有一层内存缓存 · 【必会】你直接改 MySQL 里的数据，页面也可能不变——不是坏了，是缓存。重启后端，或在后台保存一次
浏览器自己的缓存 · 【看得懂】强刷 / F12 勾 Disable cache
在哪个文件夹里敲命令 · 【必会】命令是"在当前文件夹里找东西"的，目录错了就说找不到。cd 加 pwd 两个动作练熟
双击启动网站.bat 背后干的就是上面那几条命令 · 【看得懂】不必会写，但要知道点开那两个黑窗口是干什么的——后端报错只看那个窗口

过关检验：把首页大字标题随便改一个字，走一遍"改文件 → build → 强刷 → 看到变化"。
再故意只改文件不 build，确认它不变。两个方向都试过一次，这一关才算过。

阶段 1：JavaScript 最小必需 —— 1 周【最高优先】

这是唯一的拦路虎，跨过去后面全是顺的。

内容为什么
变量、if、for、函数 · 【必会】不解释
数组 [] 和对象 {} · 【必会】JSON 就是它的写法，接口传的就是这东西
fetch() / axios + async/await · 【必会】项目里前端要数据只有这一种动作
try / catch · 【必会】后端会拒你（400/404），你要知道去哪看它说的原因
用 JS 生成 <tr><td> 填表格 · 【必会】对比页就是这张表
模板字符串 ` · 【必会】拼 HTML 用
Array.map / filter · 【必会】前端到处在用（比如把 "1,2,4" 切成数组）
类、继承、原型链 · 【别学】这项目不需要
TypeScript · 【别学】开题报告写的就是 JavaScript

过关检验：demo/step1/ 那个小演示仍然是最好的练手场——它不用 build，改完刷新就见效。
把里面两台手机改成三台，表格自动多一列。做到了这一关就算过了。
