模板页清单

这 12 页全是 VuePress Theme Hope 模板自带的演示，不是你写的内容。挨个点一下，看哪些要留。

它们现在都在 sitemap 里（15 条 URL 里占 11 条），也就是搜索引擎能搜到这些假内容。

已删除（6 页）

guide/ 那 5 页脚手架（指南 / Bar / Baz / Foo / Ray）和 portfolio.html 档案主页已经删掉了，sidebar.ts 里对应的"文档"分组和 portfolio 条目也一并去掉了。这些文件都还在 git 历史和 GitHub 上，要恢复随时能拉回来。

我建议留着的（能当字典查，2 页）

  • Markdown 展示 — 323 行。这个不是垃圾，它把这主题支持的全部 Markdown 语法都演示了一遍：代码块、公式、流程图、时间线、选项卡、提示框、脚注、任务列表……你以后写算法页想用什么语法，来这页抄。建议留着当参考手册
  • 页面配置 — 125 行。列出 frontmatter 全部可选项（封面、摘要、时间、分类、标签、是否显示导航……）。你以后调页面行为时会用到

你看完再定的（4 页）

  • 主要功能与配置演示 — 9 行，只是 demo 目录的入口页
  • 布局与功能禁用 — 42 行，演示怎么隐藏侧边栏/评论/页脚。如果你以后要做"算法页不带侧边栏"，这页有用（顺便说：我试过 pure: true 那招在这版主题上不生效，这页里可能有能用的写法）
  • 布局 — 31 行，演示几种页面布局长什么样
  • 密码加密的文章 — 15 行，就是那个密码 1234 的页面。它的密码是明文提交在仓库里的，而且前端加密挡不住有心人。你并没有真正要加密的内容，这页和 theme.ts 里那段配置都可以删

一句总结

真正可以放心删的 guide/ 5 页和档案主页已经删完了。剩下建议留的是 demo/markdown.html 和 demo/page.html（当手册用），另外 4 页等你点完定。

要再删的话说一声，我会连带 theme.ts 里的 encrypt 配置、sidebar.ts 里对应条目一起清掉，不留半截链接。
